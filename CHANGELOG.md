# Changelog

Notable changes to open-twin. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/). How releases are made is described
under [Releases](Contributing.md#releases).

## [Unreleased]

### Added

- Cohort Studio (`pnpm studio`): a local page to build a synthetic Synthea
  cohort by age, sex, place and conditions, run it, and explore the result.
  Each run saves a recipe that reruns it with `pnpm cohort <recipe>`.
- `tools/synthea/generate.sh` takes optional age, sex, city, keep-module,
  custom-modules and output-folder inputs. `manifest.json` records the age, sex,
  city, module hashes and a checksum of the patient files.

### Fixed

- The Synthea recipe is reproducible: `generate.sh` passes a fixed reference
  and end date, runs Java in UTC and uses one generator thread, so the same
  inputs give the same patient files in any folder and time zone.
  `configHash` no longer depends on the checkout path, so its value differs
  from manifests written before this change. Cohorts generated before
  this change cannot be regenerated byte for byte; see
  [docs/synthea.md](docs/synthea.md).
